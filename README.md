# RoadGuard AI

**Терең оқыту негізінде жол жабынындағы жарықтарды анықтаудың интеллектуалды жүйесін әзірлеу**

Жұмыс істейтін оқу прототипі: DeepCrack датасеті → ResNet18 CNN → оқытылған MLP классификатор → Python HTTP API → қазақша веб-интерфейс.

## Іске қосу

Python 3.12 және қажетті кітапханалар осы компьютерде бар. `start.bat` файлын ашыңыз немесе жоба папкасында орындаңыз:

```powershell
python app.py --port 8000
```

Браузерде http://127.0.0.1:8000 ашыңыз. Сервер жұмыс істеп тұрған терминалды жаппаңыз. Тоқтату: Ctrl+C. Басқа порт қажет болса, мысалы `--port 8001`.

Басқа компьютерде алдымен:

```powershell
python -m pip install -r requirements.txt
```

Сақталған модель бар кезде интернет те, GPU да қажет емес. Веб-шрифт қолжетімсіз болса, жүйелік шрифт қолданылады.

## Нақты test нәтижесі

| Метрика | Нәтиже |
|---|---:|
| Accuracy | 90.44% |
| Precision, жарық класы | 92.38% |
| Recall, жарық класы | 89.88% |
| F1, жарық класы | 91.11% |

Test: **237 бастапқы датасет суреті, 2 844 бөлік**, 1 551 positive / 1 293 negative. Confusion matrix: TN=1178, FP=115, FN=157, TP=1394. Барлық төрт метрика 85%-дан жоғары.

**Бұл метрикалар 128×128 кіріске келтірілген сурет бөліктеріндегі жарық бар/жоқ жіктеуіне қатысты.** Толық дрон кадры, пиксельдік сегментация немесе үш қауіп деңгейінің дәлдігі емес. Test нәтижесін интерфейс `reports/metrics.json` файлынан оқиды.

## Интерфейс мүмкіндіктері

- JPG/PNG/WebP жүктеу, drag-and-drop, үш нақты мысал суреті.
- Жарық бар бөліктерді сурет үстінде түсті тормен белгілеу; торды өшіру/қосу.
- «Жарық анықталмады», «Зақым бар», «Қауіпті жағдай» нәтижелері.
- Демонстрациялық трасса таңдау және маршрут схемасы. GPS анықталмайды.
- Өңдеу уақыты, белгіленген бөліктер саны, олардың аудан үлесі.
- JSON есепті жүктеу және осы браузерде соңғы 50 тексерудің тарихы.
- Нақты метрикалар, архитектура және confusion matrix беті.
- Жүктелген фото серверде файлға сақталмайды; тарихта фото емес, атауы және нәтиже сақталады.

## Модель қалай жұмыс істейді

1. Фотоның EXIF бағыты түзетіледі, RGB-ге ауысады; үлкен фото ең көбі 1024×1024 шегіне пропорционал кішірейтіледі.
2. Фото шамамен 128 px өлшемді, қабаттаспайтын бөліктерге бөлінеді.
3. ImageNet normalization → ResNet18 → 512-dimensional feature vector.
4. Оқытылған head: Linear(512,128) → ReLU → Dropout(0.3) → Linear(128,1) → Sigmoid.
5. Validation арқылы таңдалған шек: 0.65. Осы шектен жоғары бөлік «жарық бар» болып саналады.
6. Жарық анықталған бөліктер ауданы / толық сурет ауданы бойынша демо деңгейі есептеледі: 0% — жарық жоқ, 0–35% — зақым бар, ≥35% — қауіпті жағдай.

ResNet18 — **deep learning CNN моделі**. Оның ImageNet салмақтары бекітіліп, жаңа деректерге арналған нейрондық head оқытылған (transfer learning). Бұл нұсқада backbone толық fine-tuning жасалмайды. `models/cracknet.pt` ішінде backbone және head салмақтарының екеуі де бар. Inference кезінде алдын ала оқытылған салмақтарды қайта жүктеу қажет емес.

Қауіп деңгейі — **ережеге негізделген демонстрациялық бағалау**, бөлек үйретілген multiclass модель емес. Үлес жарықтың нақты пиксель ауданын/енін/тереңдігін көрсетпейді. Инженерлік тәуекелді растау үшін масштаб, биіктік, жол түрі және маман белгілеген severity деректері қажет.

## Датасет және оқыту

Дереккөз: [DeepCrack авторларының репозиторийі](https://github.com/yhlleo/DeepCrack).

Liu, Yahui et al. *DeepCrack: A Deep Hierarchical Feature Learning Architecture for Crack Segmentation*. Neurocomputing 338 (2019), 139–153. DOI: [10.1016/j.neucom.2019.01.036](https://doi.org/10.1016/j.neucom.2019.01.036).

Лицензия: **тек коммерциялық емес зерттеу және оқу мақсаттарына**. Авторлардың толық мәтіні `data/raw/DeepCrack-master/README.md` ішінде. Архив URL және SHA-256: `data/raw/provenance.json`.

Жинақта жолмен қатар басқа беттердің жарықтары бар. Барлық 537 белгіленген сурет пайдаланылады. Авторлардың 237 test суреті сақталды; 300 train суретінің 240-ы train, 60-ы validation болып бөлінді (`seed=42`). Бір датасет суретінен кесілген бөліктер әртүрлі split-ке түспейді. Суреттің RGB SHA-256 бойынша дәл көшірмелері тексеріледі. Бұл тексеру бір жол учаскесінің ұқсас кадрларын немесе бастапқы үлкен сахнадан алдын ала кесілген әртүрлі фотоларды толық анықтамайды; site-disjoint drone benchmark деп түсіндіруге болмайды.

| Split | Сурет | Бөлік | Жарық бар | Жарық жоқ |
|---|---:|---:|---:|---:|
| Train | 240 | 2 880 | 1 471 | 1 409 |
| Validation | 60 | 720 | 356 | 364 |
| Test | 237 | 2 844 | 1 551 | 1 293 |

Маскадағы кемінде бір жарық пикселі бар бөлік positive. Маскасы толық бос бөлік negative. Синтетикалық negative жасалмайды, қиын/ұсақ жарықтар test-тен алып тасталмайды.

100 epoch, AdamW, lr=0.001, weight_decay=0.01, batch=128, weighted BCE. Ең жақсы epoch: **18**. Модель және threshold тек validation арқылы таңдалды. Test нәтижесі checkpoint бекітілгеннен кейін есептелді.

Қайта жасау:

```powershell
python scripts/download_data.py
python scripts/prepare_data.py
python scripts/train.py --epochs 100
python scripts/train.py --evaluate
python scripts/make_samples.py
python app.py
```

`data/features.pt` — CPU уақытын үнемдейтін бекітілген CNN белгілерінің кэші. Датасет/manifest/трансформация/backbone өзгерсе, кэшті қайта жасау керек. Модельді қайта оқыту `models/cracknet.pt` файлын алмастырады; қажет болса алдыңғысын алдын ала көшіріңіз. Нұсқалар мен CPU айырмасынан кіші сандық ауытқулар болуы мүмкін.

Сервер іске қосылғанда тексеру:

```powershell
python scripts/verify.py --port 8000
```

## Файлдар

- `app.py` — жергілікті сервер және нақты модель inference.
- `model.py` — ортақ архитектура/алдын ала өңдеу.
- `models/cracknet.pt` — толық оқытылған модель (шамамен 43 MB).
- `data/manifest.json` — әр бөліктің жолы, label, source, split, box, mask coverage.
- `scripts/` — жүктеу, дайындау, оқыту, бағалау, тексеру.
- `reports/metrics.json` — test метрикалары және split статистикасы.
- `reports/test_predictions.json` — әр test бөлігі бойынша нақты болжам.
- `reports/training_history.json` — loss және validation метрикалары, барлық epoch.
- `web/` — веб-интерфейс және мысал суреттері.

## Курстық жұмыс материалдары

- `RoadGuard_курстық_жұмыс.docx` — курстық жұмыстың Word нұсқасы.
- `RoadGuard_AI_стартап_есебі.docx` — жоба бойынша стартап есебі.
- `coursework/final.pdf` — курстық жұмыстың PDF нұсқасы.
- `coursework/startup/final.pdf` — стартап есебінің PDF нұсқасы.
- `coursework/figures/` — жұмыста қолданылған сызбалар мен интерфейс суреттері.
- `coursework/*.py` — құжаттар мен суреттерді дайындауға арналған сценарийлер.

Бастапқы DeepCrack архивтері репозиторийге қосылмайды. Оқыту қажет болса, `scripts/download_data.py` архивті бастапқы дереккөзден қайта жүктейді; лицензиясы коммерциялық емес зерттеу және оқу мақсаттарын ғана қамтиды. Қосылған `models/cracknet.pt` inference үшін жеткілікті, ал оқыту деректерін дайындау үшін `scripts/prepare_data.py` іске қосылады.

`coursework/reference*.pdf`, уақытша каталогтар және қайталанатын PDF render-лер репозиторийден тыс қалады. Негізгі қорытынды құжаттар мен олардың дереккөз сценарийлері сақталады.

## Қолданылу шегі

Бұл нұсқа фотомен жұмыс істейді. Дронды басқару, GPS/телеметрия, RTSP/video ағыны жоқ. API кадр бойынша интеграциялауға негіз болады, бірақ real-time бейне жылдамдығы тексерілмеген. Асфальт, көлеңке, жол сызығы, жоғары биіктіктен түсірілген кадр, шұңқыр және жарық емес объектілерде қателесу мүмкін; модель барлық жол зақымдарын емес, жарықтарды үйренген. Жергілікті дрон фотоларын белгілеу және бөлек тест қажет.

Сервер тек `127.0.0.1`-ге байланады және жергілікті оқу демосына арналған. Бұл Python стандартты HTTP сервері; public production hosting емес.
